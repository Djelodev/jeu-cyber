# CyberQuest — Sécurité du SI (ESGI)

Quiz de révision en français basé sur le support « Sécurité du système d’information », ESGI Toulouse, 2026–2027.

## Fonctionnalités
- 100 questions à choix multiples réparties sur 13 thèmes.
- 5 vies par partie ; chaque mauvaise réponse retire une vie.
- Correction expliquée après chaque réponse.
- En cas de défaite, récapitulatif des erreurs avant de recommencer.
- Progression conservée localement dans le navigateur.
- Interface mobile et prise en charge d'un usage hors ligne après la première visite (service worker).

## Publication
Le workflow `.github/workflows/deploy-pages.yml` est prêt à publier le site sur GitHub Pages. L’activation initiale de GitHub Pages doit être faite une seule fois dans Settings → Pages → Build and deployment → Source : GitHub Actions.
Après l’activation et un déploiement réussi, l’adresse du jeu sera : https://djelodev.github.io/jeu-cyber/

## Sur iPhone
1. Ouvrir l’adresse dans Safari.
2. Toucher le bouton Partager.
3. Choisir « Sur l’écran d’accueil » puis « Ajouter ».

Le dépôt et le site sont publics. Ne pas y placer de données personnelles ou d’informations confidentielles.
